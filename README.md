# 🎓 แนะนำการใช้งานระบบนำเสนอบน GitHub Pages

โฟลเดอร์ `docs/` นี้ถูกสร้างขึ้นเป็น **Pure HTML, CSS, JavaScript** โดยไม่ต้องใช้ Node.js หรือเซิร์ฟเวอร์ฐานข้อมูล สามารถนำไปขึ้น **GitHub Pages** เพื่อใช้ในการนำเสนอโปรเจกต์ (Presentation / Showcase) ได้ทันที

---

## 🚀 วิธีเปิดใช้งานบน GitHub Pages

1. **Push โค้ดขึ้น GitHub**:
   ```bash
   git add docs/
   git commit -m "Add GitHub Pages demo in docs folder"
   git push origin main
   ```
2. **เปิดการตั้งค่า GitHub Pages**:
   - ไปที่หน้า Repository บน GitHub ของคุณ
   - คลิกแท็บ **Settings** ด้านบน
   - ที่เมนูด้านซ้าย เลือก **Pages**
   - ในส่วน **Build and deployment**:
     - **Source**: เลือก `Deploy from a branch`
     - **Branch**: เลือก `main` (หรือ branch หลักของคุณ)
     - **Folder**: เลือก `/docs` 👈 *(สำคัญมาก)*
   - กดปุ่ม **Save**
3. รอประมาณ 1–2 นาที GitHub จะแสดงลิงก์ URL ให้เข้าใช้งานได้ เช่น:
   `https://<username>.github.io/<repo-name>/`

---

## 💻 วิธีเปิดทดสอบในเครื่องทันที (Local)

- ดับเบิลคลิกเปิดไฟล์ `docs/index.html` ด้วยเบราว์เซอร์ใดก็ได้ (Chrome, Edge, Firefox, Safari) ใช้งานได้ทันทีโดยไม่ต้องรันคำสั่งใดๆ

## ✨ ฟีเจอร์ที่เตรียมไว้สำหรับการนำเสนอโปรเจกต์

| หน้าจอ / ฟีเจอร์ | รายละเอียดสำหรับการพรีเซนต์ |
|---|---|
| **📊 Dashboard (แดชบอร์ด)** | สรุปจำนวนผู้สมัครแต่ละกลุ่ม (ผ่าน / รอพิจารณา / ไม่ผ่าน / รอตรวจเรียงความ), กราฟกระจายคะแนน (Score Distribution 0–100), แบนเนอร์จริยธรรม |
| **👥 รายชื่อผู้สมัคร (Applicants Table)** | ค้นหาชื่อ/รหัส, ตัวกรองสถานะ, กรองเฉพาะที่มี Flag, เรียงลำดับคะแนน/GPA, แสดงแท็ก "ใหม่" และ "อัปเดต" |
| **📄 รายละเอียดรายบุคคล (Detail Modal)** | แสดงข้อมูลละเอียด (GPA, รายได้, กิจกรรม, เอกสาร), แสดงการคำนวณคะแนน 4 หมวดแบบโปร่งใส (Explainability), แสดงรายการ Flag |
| **⚖️ Human-in-the-Loop Override** | กรรมการสามารถปรับเปลี่ยนผลการตัดสินได้อิสระ โดยมีเงื่อนไขจริยธรรมบังคับให้ระบุชื่อกรรมการและเหตุผล |
| **⚙️ ปรับเกณฑ์ & จำลองผล (Policy Simulation)** | สไลเดอร์ปรับค่าน้ำหนัก 4 หมวด (รวม 100%) พร้อมคำนวณผลกระทบแบบเรียลไทม์ (Live Impact Analysis) ว่ามีผู้สมัครย้ายกลุ่มกี่คน |
| **📥 นำเข้า/ส่งออก (CSV Batch Import & Export)** | มีปุ่ม "โหลดไฟล์ตัวอย่าง (Sample CSV)" และ "ดาวน์โหลด Template" จำลองการนำเข้าข้อมูลและการตรวจสอบความถูกต้อง |
| **📋 Audit Log** | บันทึกประวัติการตัดสินใจ การ Override และการแก้เกณฑ์ย้อนหลัง เพื่อความโปร่งใสและตรวจสอบได้ (Accountability) |
| **⚖️ หลักจริยธรรม 4 ประการ** | สรุปกรอบแนวคิดจริยธรรม AI และ PDPA ที่นำมาใช้ในการออกแบบระบบ |
